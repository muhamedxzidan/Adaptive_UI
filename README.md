**Breaking communication barriers with real-time sign language translation.**  
SignSight is an intelligent Flutter application designed to bridge the gap between sign language users and non-signers through real-time camera translation, text-to-speech, and an adaptive user interface.

## ✨ Key Features

- **📷 Real-time Translation:** Uses the camera to capture and interpret sign language gestures instantly.
- **🗣️ Voice Output:** Converts translated text into spoken audio for clearer communication.
- **📝 Text Translation:** Translates signs directly into readable text.
- **📐 Adaptive Layouts:**
  - Uses `LayoutBuilder` to intelligently switch between `Column` (mobile) and `Row` (desktop) layouts.
  - Implements `flutter_screenutil` for pixel-perfect responsiveness across different screen densities.
- **🌗 Modern UI:** Clean, accessible design with custom components and intuitive navigation.
